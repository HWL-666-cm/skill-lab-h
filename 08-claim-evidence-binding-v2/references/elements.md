# 引言与相关工作的四要素：各自要什么证据

题面把四问写成"立得住 / 分得清 / 说得实 / 对得上"。本文件把它们翻译成可操作的断言类型与证据要求。

## 1. 研究背景（立得住）

**要求**：指向真实研究脉络与具体未解决问题，不是"近年来受到广泛关注"式空转。

**证据载体**：
- 领域脉络句 → 引用（材料文献表里的具体工作）
- 具体约束句 → 材料中的数字、阈值、场景限制（逐字引文 + 定位符）
- "为什么现在值得做" → 近期工作或材料中明确写的未解决点

**诊断信号**：套话词表（`cliche_terms`）命中即 warn，要求替换为材料里的具体问题；不自动删。

**机器不能判**：这段话是否真的"精彩"、是否真的"立住"。只判有没有锚点、有没有套话。

## 2. 相关工作（分得清）

**要求**：按问题/方法/技术路线分组比较，转述结论、适用条件、局限，不逐篇摘要拼接。

**证据载体**：
- 每条转述 → 引用锚点（key / 编号 / 作者年）
- 分组维度 → `## 相关工作` 下挂的 `###` 分组标题（问题设定/方法路线/数据与评价/适用场景）

**诊断信号**：
- `related_work_no_grouping`：相关工作 ≥2 句但 `## 相关工作` 下没有 `###` 分组标题、材料里也没有分组维度 → warn
- `key_work_not_written`：材料文献表里有、成稿完全没提到的工作 → warn（后向对齐）
- `mentioned_without_anchor`：提到作者但没引用锚点 → warn

**机器不能判**：比较是否"在同一维度上"、转述是否忠实于原文。留给人工。

## 3. 研究空白（说得实）

**要求**：由**已引文献的缺口**推出，说明本文如何填补；断言有证据或显式标为作者判断。

**证据载体**：
- 空白句 → 必须挂引用锚点（谁的什么局限）
- 或材料原文中的 limitation 句（`gap_signals` 命中的句子）→ 逐字引文 + 定位符

**诊断信号**：`gap_without_citation`（空白句无锚点）→ warn；`gap_derivation`（材料连一条 limitation/缺口表述都没有时，空白无法"由文献推出"）→ warn；gaps.md 里追问"由谁的什么局限推出"。

**机器不能判**：这个"空白"是否真的成立、是否真的没人做过。只判是否挂到了已引文献。

## 4. 贡献（对得上）

**要求**：与本文实际方法、图表、实验结果一一对应，不夸大适用范围。

**证据载体**：
- 每条贡献 → 图/表/章节/公式编号（`figure_patterns`），或材料中的逐字结果句
- 强度词（"显著提升"/"彻底解决"）→ 必须 hedge 或有证据，否则 `overclaimed`

**诊断信号**：`contribution_without_figure`（贡献句无锚点）→ warn；`hedge_overclaim`（强断言无证据）→ warn；`contribution_map`（每条贡献→章节/图表/引用的映射表，见 result.json）逐条可核对。

**机器不能判**：图表是否真的支持该贡献、提升幅度是否属实。留给人工。

## 5. 引用覆盖（贯穿四要素）

**要求**：关键工作被覆盖，元数据（作者/年份/来源）准确。

**证据载体**：材料文献表的每条 entry（BibTeX / bibitem / 编号列表 / 作者年列表）。

**诊断信号**：
- `citation_metadata_mismatch`（fail）：真作者对错年份 → 逐字段报 `year X != material Y`
- `citation_unverifiable`（warn）：引用解析不到材料条目
- `key_work_not_written`（warn）：材料关键工作未在成稿出现

**为什么把元数据单独做成硬检查**：已有量化研究显示 CS 论文引用标题幻觉率 47%（GPT-4）到 77%（Llama 2），且"真作者 + 假年份/假 DOI"的混合幻觉通过浅层检查。因此作者和年份都要逐字段核对——见 `failure-modes.md`。
