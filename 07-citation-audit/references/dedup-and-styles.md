# 去重判据与引用格式要点

## 一、去重判据（按证据强度分级）

| 级别 | 条件 | 处置 |
|---|---|---|
| 强 | 规范化 DOI 相同 **且** 题名/第一作者/年份无冲突 | `merge`：合并字段，正文两处引用统一指向保留键，写清依据 |
| 强但冲突 | DOI 相同 **但** 题名或作者或年份不同 | `keep_both_needs_review`：绝不自动合并，列出冲突字段交人工确认 |
| 弱 | 题名键 + 第一作者姓 + 年份一致，但 DOI 不同或缺失 | `duplicate_suspected`：只提示，不自动合并；常见于预印本 vs 正式版 |
| 无 | 题名相似但作者/年份不同 | 不判重复，避免误合并同名作者的不同文献 |

为什么要分强弱：DOI 是出版界给的唯一标识，可作为强证据；题名可能被不同数据库改写法（中英题名、大小写、标点），只能作为线索。若把弱证据当强证据，会犯"把同名作者的不同论文合并"的错，比不去重更糟。

## 二、编号与位置规则

**顺序编码制（GB/T 7714 常用）**
- 正文引用按**首次出现顺序**编号；先出现的引文编号必须小。
- 编号连续，不跳号、不重复；一个编号只指向一条文献。
- 多条引文：`[1,2,3]` 或连续段 `[1-3]`；脚本两种都解析。
- 文末列表顺序与正文首次出现顺序一致，删除段落必须同步重排。

**引用位置**
- 引用要紧跟**需要来源支撑的论断句**，不是整段末尾，也不是图题/表题行。
- 一句多引：同一位置并列多个键；多句一引：逐句判断是否真的都由该文献支撑。
- 图表如需来源，写"数据来源"，不要混同正文论断的引用。

## 三、GB/T 7714—2015 高频扣分点（来自公开指南，脚本覆盖其中可机器判定的部分）

| 问题 | 脚本是否检查 |
|---|---|
| 预印本误标 `[J]` | ✅ `preprint_mislabeled`（硬错误） |
| DOI 缺 `https://doi.org/` 前缀 | ✅ `doi_missing_prefix`（警告） |
| 电子资源缺 `[引用日期]` | ✅ `missing_access_date`（警告） |
| 正文与文末编号不一致 | ✅ `reference_list_mismatch`（硬错误） |
| 编号跳号/乱序 | ✅ `numbering_gap` / `first_appearance_order` |
| 缺卷号、期号、起止页码 | ⚠️ 提示字段缺失，但无法判定"应有的值"，不编造 |
| 作者超过 3 人用"等"/"et al." | ❌ 需人工按目标规范处理 |
| 中英文混排按文种分组 | ❌ 需人工按目标规范处理 |

脚本不做的事不算失败：**凡是必须靠领域知识或目标期刊细则才能裁决的，明确列为人工确认项**，不要用猜测得来的"修正"冒充正确。
