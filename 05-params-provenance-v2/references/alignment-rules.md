# 对齐规则：七类判定与忽略清单

## 两个方向，一套机制

前向回答"正文的数值有没有出处"，后向回答"材料的参数有没有写进正文"。两者共用同一个台账，所以只需要维护一份事实来源。

## 七类判定

| 判定 | 触发条件 | 读者后果 | 严重度 |
|---|---|---|---|
| `traced` | 值对上某台账行，且该参数在本段被点名 | 可核查 | — |
| `mismatch` | 本段点名了参数 P，但数字不是 P 的台账值 | 要么正文错，要么台账错，二者必有一错 | 重要 |
| `invented` | 材料里不存在这个值 | 读者查不到，章节在最像精确的地方失去依据 | 阻断 |
| `in_material` | 材料里有这个数，但没有台账行把它记为参数值 | 值是真的，归属不明 | 重要 |
| `value_only` | 值对上某行，但本段没点名该参数 | 可能是正确归属，也可能是张冠李戴 | 次要 |
| `ambiguous` | 一个值能对上多个参数，本段没说清 | 文本本身模糊 | 次要 |
| `ignored` | 命中忽略规则（见下） | 按规则不计 | — |

## 锚点选择（决定 `traced` 还是 `mismatch`）

一个数字最近的参数名就是它的锚点。三条规则，按顺序：

1. **数字之前的参数名优先，跨度 ≤ 40 字符。** 英文把值放在标签后面（"a learning rate of 0.001"）。按纯距离比，"0.001, momentum 0.937" 会把 0.001 判给紧随其后的 momentum——而这恰好是本工具最该报出来的错。
2. **数字之后的参数名只在跨度 ≤ 15 字符时成立**，用于 "8 GPUs"、"1400 epochs" 这类紧邻形式。半句之外的标签属于另一句话："at 512x512 the same token budget requires patch size 4" 不能说 512 是 patch size。
3. **标签与数字之间若还夹着另一个数字，该标签已被那个数字占用。** "patch size 2; at 512x512" 中，patch size 属于 2。设备名例外：`A100`、`P4d` 里的数字不算数量，"8 A100 GPUs" 仍然把 8 归给 GPUs。
4. **`steps/sec`、`tokens/s` 这类是单位而不是参数**，不参与锚定：0.84 steps/sec 的 0.84 是吞吐量，不是步数。

## 忽略清单（每一条都要能说出理由）

| 规则 | 例子 | 不忽略会怎样 |
|---|---|---|
| 引用标记 | `[3]`、`[12,13]` | 每句引用都被当成没有出处的数字 |
| 年份 | `2021`、`since 2019` | 综述类段落全线告警 |
| 图表/章节号 | `Table 2`、`Sec. 3.1`、`图 4` | 交叉引用被当成参数 |
| 指标名后缀 | `FID-50K`、`mAP50` | 指标名里的数字被当成设置值 |
| 模型名后缀 | `XL/2`、`B/4` | 模型变体编号被当成分辨率 |
| 相对提升 | `提升 3%`、`lower by 0.2` | 相对变化被当成绝对设置 |
| **边界条件** | `smaller than 8`、`at most 1e-4`、`不超过 4` | 适用范围的阈值被要求溯源，或反过来被判凭空 |

最后一条是设计上的取舍：边界值（"批小于 8 会不收敛"）是真实且有意义的断言，但它不是某个设置的值，既无法对上台账，也不该被指控为编造。所以单列 `ignored` 并写出理由，让人看得见。代价是：如果有人在这里写一个假阈值，本工具不会报警——这一点写在「已知边界」里，不掩饰。

## 单位与写法归一

同一个值有四种写法，必须判等，否则 `mismatch` 会变成噪声工厂：

| 写法 | 归一后 |
|---|---|
| `1e-4`、`1E-04`、`1 × 10⁻⁴`、`0.0001` | 0.0001 |
| `250 ms` / `0.25 s` | 0.25（秒） |
| `400K`、`50K` | 400000、50000（数量级后缀，不是温度） |
| `50_000` | 50000（下划线千分位） |
| `256x256`、`8x A100` | 256（尺寸对）、8（设备倍数） |
| `10%` 与 `0.1`（仅在 rate/ratio/dropout/split 这类名字下） | 判等，并记一条"百分号写法差异"备注 |

百分比只在**比例类参数名**下判等：`10%` 与 `0.1` 是同一件事，但 `accuracy: 10%` 与 `accuracy: 0.1` 不是。

## 后向的三种状态

| 状态 | 含义 |
|---|---|
| 已写 | 本段点名了该参数，且值被追溯到 |
| 提了没给值 | 点名了参数却没有值——读起来像披露，实际不给读者任何东西 |
| 没写 | 台账有行，正文一处没提 |

后向的「没写」按参数名聚合，并且**只对训练设置类家族（optim/schedule/data/runtime/reproducibility）判重要**：一张模型规模表天然会省略每个变体的行，训练设置没有这个豁免权。
