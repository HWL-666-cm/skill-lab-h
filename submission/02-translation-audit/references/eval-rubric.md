## 二、交付前自查（逐条打勾）

**结构**
- [ ] 已跑 `pdf_paragraphs.py`，`kinds` 里有 `para`，且 `para` 数量与直觉相符（不是 0、不是全量）
- [ ] `issues` 里的 `paragraph_continuation` 已人工确认
- [ ] 有扫描页时已标注，没有编造文本

**术语**
- [ ] 术语表 `target` 全部填写，`locked=true`
- [ ] 全称已收紧（无多余修饰语）、无动词误收
- [ ] 易混译法已写入 `forbidden`
- [ ] 译文里没有 `forbidden` 里的词

**翻译**
- [ ] 每个 `para` 都有译文（或用 `--scope` 明确只做局部）
- [ ] 数字、单位、引用年份、图表编号都保留
- [ ] 否定与限定强度未被升级
- [ ] 译不准处有 `【待核】` 且进 `uncertainties`

**审计**
- [ ] `verdict` 不是 `needs_revision` 就交付；若是，逐条修完再跑
- [ ] `warning` 已逐条判断并记录
- [ ] `status` 诚实（缺段/硬错误 → `partial`）

**产物**
- [ ] `result.json` 含 `case_id`、`status`、`translation`、`glossary`、`audit_report`、`source_map`
- [ ] `bilingual.md`、`glossary.csv` 已生成
- [ ] 没有把示例当正式结果

## 三、常见误判与处理

| 现象 | 是误报吗 | 处理 |
|---|---|---|
| 中文译名后接英文缩写导致 `unit_lost` | 可能 | 若单位语义已由中文表达，记录为可接受 |
| `term_overused` 但确属同一概念换段表述 | 可能 | 人工确认后记录，不改脚本口径 |
| 术语表未锁 → `glossary_unlocked` | 不是 | 必须补 `target` |
| 局部翻译未给 `--scope` → 大量 `missing_paragraph` | 不是 | 加 `--scope` 重跑 |
| 表格行被标 `fragment` 未译 | 视任务 | 若任务要求译表，人工补译并标为 `table` |
