# 实测指标（只登记题录，不含原文）

本文件记录本 Skill 在**真实论文**与**合成件**上的实测数字。原文与解析产物均不进提交包
（只保留题录与指标），可复算的脚本在 `scripts/run_selftest.py` 与 `tests/make_cases.py`。

测量口径全部是**坐标与字符计数**，不含主观打分：

| 指标 | 定义 | 脚本 |
|---|---|---|
| 跨栏跳转 | 阅读顺序中相邻两项横向位移 > 150pt 的次数，按页平均 | `_validation` 内 `measure_ab.py`（同逻辑已写进 `references/layout-rules.md`） |
| 回跳 | 相邻两项 `dx < -150` 且 `dy < -20`（既大幅左移又上移）——串栏交错的指纹 | `layout.reading_order_metrics` |
| 正文覆盖率 | 正文段落字数 / 页面非页眉页脚字数 | 同上 |
| 归类覆盖率 | （正文+题注+表单元格+公式+文献+脚注+标题作者摘要）字数 / 非页眉页脚字数 | 同上 |
| 锚点通过率 | bbox 回抽原文、按类型阈值判定通过的单元占比 | `anchors.audit` |

## 三、合成件（可复现，`scripts/run_selftest.py`）

全部用例由 `tests/make_cases.py` 现场生成，不依赖任何外部素材。

| 用例 | 检验什么 | 结果 |
|---|---|---|
| `single_column` | 单栏 + `Abstract.` 独立成段 + 3 个编号章节 + 1 张有线表 | `ok`，3 页 / 10 段 / 3 章节 / 1 表，锚点 1.00 |
| `two_column` | 通栏标题摘要 + 左右各 4 段 | `ok`，`2col`，25 段，回跳 0（27 个相邻对），锚点 1.00 |
| `three_column` | 三道栏缝定位、不把三栏正文误判成表格 | `ok`，`3col`，19 段，表格 0 张（无假表），锚点 1.00 |
| `cjk_single` | 中文 + 全角空格 + 全角数字 | `ok`，标题与"海雾"正文正确提取，锚点 1.00 |
| `scanned` | 整页贴图、无文字层 | `partial`，`needs_ocr_pages=[1,2]`，正文 0 段，`anchor=null` |
| `encrypted` | AES-256 用户密码 | `blocked`，`reason="PDF 需要密码，空密码也无法打开"` |
| `long_doc` | 60 页双栏 | `ok`，360 段 / 12 章节，1.2 s，锚点 1.00 |

单元断言（5 条）：NBSP 归一、软连字符删除、`fi/fl` 连字展开、行尾断词合并、私用区乱码计数。

## 四、怎么复算

```bash
# 1) Skill 自身的行为断言（不需要任何外部 PDF）
python scripts/run_selftest.py

# 2) 换你自己的论文跑一遍，然后看这四个数
python scripts/run_case.py --pdf your.pdf --output out/
python - <<'PY'
import json
m = json.load(open("out/run_meta.json"))
print("锚点通过率", m["anchor_pass_rate"])
print("覆盖缺失", [c["key"] for c in m["coverage"] if not c["present"]])
print("耗时", m["elapsed_s"], "秒", m["page_count"], "页")
PY
```

判读标准：`anchor_pass_rate ≥ 0.95` 且 `coverage` 缺失项都能在 `uncertainty` 里找到解释，
就可以直接用；低于 0.90 先去 `anchors.json` 看失败的是哪类单元。

## 五、这份基准不覆盖什么

- **不覆盖**扫描件的 OCR 准确率（本 Skill 只做路由与如实标注，不内置 OCR 引擎）。
- **不覆盖**异常字体导致的全篇乱码（只有单元级断言）。
- **不覆盖**旋转页、双面拼版、竖排古籍。
- 两篇样本都是英文学术期刊版式；中文样本只有合成件，未在真实中文期刊 PDF 上大规模验证。
