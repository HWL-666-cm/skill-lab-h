# 异常分支与诚实降级口径

原则只有一条：**读不出来就说读不出来，并说清是哪一页、哪一块、为什么。**
补一段"看起来合理"的假正文，比少给一段更严重——评审和下游都无法区分。

下面每一条都能在 `tests/` 的合成件或公开论文上复现；`status` 列是这种情况下 `result.json` 该有的值。

---

## 1 PDF 打不开：有密码

| 项 | 内容 |
|---|---|
| 症状 | `doc.needs_pass == True` |
| 处置 | 只尝试**空密码**（大量 PDF 只设了权限位、没有用户密码，空密码能开） |
| 失败时 | `status=blocked`，`reason="PDF 需要密码，空密码也无法打开"`，`handover.needs_human=true` |
| **不做** | 不尝试暴力破解、不去猜内容、不输出"大概是这样"的正文 |
| 复现 | `tests/make_cases.py` 的 `encrypted`（AES-256，用户密码 `secret`） |

## 2 无文字层：扫描件

| 项 | 内容 |
|---|---|
| 症状 | 该页 `chars == 0` 且 `images > 0` |
| 处置 | 该页 `route=ocr`，**不做任何几何推断**（没有文字层时，任何坐标推断都是编造）；不产出正文段 |
| 状态 | 有 OCR 页 → `partial`；整篇都是 → 仍然 `partial`（不是 `ok`，也不是 `blocked`） |
| 说明 | 在 `uncertainty` 写明"第 N 页无可用文字层，已路由 OCR/标注不可读" |
| 上限 | OCR 的准确率由扫描分辨率决定；**< 200 DPI 时任何引擎都救不回来**，此时应要求用户提供更好的扫描件 |
| 复现 | `scanned`（150 DPI 渲染后整页贴图）：`needs_ocr_pages=[1,2]`、`body_paragraphs=0`、`anchor=null` |

## 3 乱码文字层：ToUnicode 坏了

| 项 | 内容 |
|---|---|
| 症状 | 抽出的文本里私用区字符（U+E000–U+F8FF）、替换符 U+FFFD、`(cid:N)` 占比 > 3% |
| 为什么文本层无解 | 字符→Unicode 的映射表（ToUnicode CMap）缺失或错误，字形在、语义没了。**更隐蔽的是错映射**：某字体 GID 127 本应是 `Σ`，ToUnicode 却指向拉丁 `S`——视觉正确、语义错误，任何基于文本层的解析都发现不了 |
| 处置 | `route=ocr` + 记 `garbled_text_layer` flag；同时保留 `fonts_missing_tounicode` 计数作证据 |
| 已知短板 | 若乱码率低于 3% 阈值（例如只有几个符号错映射），本 Skill **不会**发现，需人工抽查公式与符号 |
| 复现 | 单元断言 `garbled_pua`；整篇乱码件需构造异常字体，未纳入合成集（见"已知缺口"） |

## 4 文字被转曲（轮廓化）

| 项 | 内容 |
|---|---|
| 症状 | `chars < 60` 且 `drawings > 80` 且 `images == 0` |
| 含义 | 文字被转成矢量路径，文本层彻底不存在（不是"识别错"，是"没有字符"） |
| 处置 | `route=ocr`，flag `text_as_outlines` |
| 复现 | 合成集未含（构造需要把字转曲），逻辑见 `pdfcore.triage_page` 分支 |

## 5 表格检测失败

| 项 | 内容 |
|---|---|
| 症状 | 区域里词分布不像表，或校验不通过（列数、非空率、像散文…） |
| 处置 | `status=detected_unstructured`，保留 `region`、题注、`reject_reasons`，**不输出 `matrix`** |
| 状态 | 有未结构化表 → `partial` |
| 正确用法 | 按 `region` 的页码去看原页（或走 OCR），**不要**把这种表的 `matrix` 当数据 |
| 常见原因 | 无竖线且列间空白 < 7pt（列粘连）；表体被图覆盖；多层表头；表格本身是图片 |

## 6 跨页续表

| 项 | 内容 |
|---|---|
| 判据 | 列数相同 + 表头相似（或题注带 `continued`）+ 位于下一页顶部 + 页码连续 |
| 不满足时 | 当作两张独立表，**不强行合并**（合错比不合并更难发现） |
| 已知缺口 | 续表第二页若重复表头，当前实现会把它当数据行保留（`continued=true` 时可见） |

## 7 公式

| 情况 | 处置 |
|---|---|
| 只找到编号 `(3)` 没找到主体 | `status=number_only`，写进 `uncertainty`："只定位到编号，公式本体未能可靠提取" |
| 主体找到但无编号 | `status=unnumbered`（不编造编号） |
| 符号被拆散 | `text_raw` 保留原始顺序，`text_scripted` 给还原版本；两者都不改字符本身，只标上下标 |
| 公式是图片 | 抽不到字符，会落进 `figures` 或直接缺失；`uncertainty` 里说明 |

> 不追求"转成完美 LaTeX"。追求：符号保真 + 编号对照 + 区域截图可人工核对。

## 8 多栏被合并成一行

| 项 | 内容 |
|---|---|
| 症状 | PyMuPDF 把相邻栏同一基线的字合进一行，读出来"左栏行尾接右栏行首" |
| 处置 | 取行时按内部大间隙（> 1 倍字号）切段；已覆盖间隙 ≥ 6pt 的情况 |
| 已知缺口 | 若栏间距**小于 1 倍字号**（很紧的三栏排版），切不开，会串栏。此时靠 `anchor` 覆盖率下降 + 人工抽查发现 |
| 复现 | 合成件 `three_column`（修正后 19 段、锚点 1.00） |

## 9 竖排 / 旋转页

| 项 | 内容 |
|---|---|
| 现状 | 记录 `rotation`，但**不做坐标旋转校正**；旋转 90° 的页会按未转坐标系解析，行列判断可能失效 |
| 处置 | 出现在 `triage` 里可查；`uncertainty` 不自动写（因为多数 PDF 已把 `/Rotate` 应用到页面矩形） |
| 建议 | 遇到 `rotation != 0` 的案例，人工确认一次 `document.md` |

## 10 中文文档

| 项 | 内容 |
|---|---|
| 已处理 | 全角空格 U+3000、全角数字（`nfkc` 单独用于数值比对）、中文标点、无空格分词的行 |
| 章节判据 | 编号后允许汉字开头；`1　引言`（含全角空格）能识别 |
| 断词 | 中文没有大小写，续段判定退化为"上一段无句末标点 + 同章节" |
| 复现 | 合成件 `cjk_single`（含全角数字、全角空格的标题与摘要） |

## 11 预算与超时

| 项 | 内容 |
|---|---|
| 现状 | 纯本地脚本，**无网络**；单页成本约 20–30ms（60 页双栏约 1.2s，14 页双栏约 2.8s） |
| 超长文档 | 若单次运行超过预算，先落已完成的产物（`document.json` 是流式写入前全部在内存构建，因此建议按页分段调用，见下） |
| 分段策略 | `python scripts/build.py --pdf big.pdf --outdir out/` 一次性跑完；页数 > 500 时建议先用 `pdfcore.triage_document` 抽样，确认没有大量 OCR 页再整篇跑 |
| 已知风险 | 单页含数百条矢量图元时 `get_drawings()` 会成为热点 |

## 12 依赖缺失

| 项 | 内容 |
|---|---|
| 症状 | `import pymupdf` 失败 |
| 处置 | `status=blocked`，`reason="缺少运行依赖 PyMuPDF"`，`detail` 带原始异常与 `pip install 'pymupdf>=1.23'` 提示；同时写 `traceback.txt` |
| 为什么这样写 | 契约没有逐条保证镜像里装了 PyMuPDF；崩在 import 时调用方只看到栈，既不知道装什么也拿不到结构化结果 |
| 可选依赖 | Pillow 缺失时跳过公式截图，记一条 `uncertainty`，其余功能不受影响 |

## 13 明确不做的事（以及为什么）

| 不做 | 原因 |
|---|---|
| 不引入深度学习版面模型（docling / marker / layoutlm） | 运行预算是 64 请求 / 900 秒、且不能假设可联网装模型；几何规则 + 一致性校验更稳、更可解释、每一步都能指向证据 |
| 不让 LLM 改写正文 | "逐字一致"是硬指标。文本一律来自 PDF 提取，LLM 只做判定与说明 |
| 不追求表格 100% 还原 | 追求"结构可核验 + 读不出就标注"。编造列比少认一张表扣分更重 |
| 不猜加密文件内容 | 打不开就是打不开 |

## 已知缺口（诚实清单）

1. 整篇乱码件（异常字体）没有纳入合成自测，只有单元级断言。
2. 转曲文字（`text_as_outlines`）分支同样只有逻辑、没有合成件。
3. 栏间距小于 1 倍字号时，跨栏合行切不开。
4. 无 `Abstract` 标签的期刊（如部分 Scientific Reports 版式），摘要按"标题后第一个长正文段"推断；
   若该版式的摘要区是窄栏排版，摘要的后续行可能被判成正文（会写进 `uncertainty`）。
5. 旋转页不做坐标校正。
6. 续表第二页重复的表头会作为数据行保留。
