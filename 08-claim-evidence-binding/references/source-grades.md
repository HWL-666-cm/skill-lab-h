# 来源分级与适用边界

## 材料形态与可信度

| 形态 | 读者 | 抽取能力 | 限制 |
|---|---|---|---|
| LaTeX `.bib` | 内置解析 | `@article{key,...}` → 作者/年份/标题/期刊精确抽取 | 只解析花括号字段，复杂宏可能丢 |
| LaTeX `.tex` 内嵌 `\bibitem` | 内置解析 | `\bibitem{key}` → key/作者/年份/标题 | 标题含 LaTeX 宏会残留（如 `~`、`{-}`） |
| Markdown / RST / TXT | 内置解析 | 逐行 + `[1]` 编号列表 + `Author (Year).` 列表 + 逐字引文 | 无结构的散文只能做逐字引文定位 |
| JSON / YAML | 内置解析 | 键值抽取、表格识别 | 字段名按语义读，不假设固定键 |
| PDF | 可选 pymupdf/pypdf/pdftotext | 抽文本层后按上表处理 | 扫描件无文本层 → 记 unreadable，不假装核对过 |
| DOCX | 可选 python-docx | 抽段落文本 | 图片里的文字读不到 |

题面明确要求"读真实文件，不按标签假设内容"——本 Skill 按文件实际后缀与内容探测，不信任 case.json 里的领域标签。

## 引用元数据核对的边界

能核对：引用 key 是否在材料文献表、年份是否与材料一致、作者姓氏是否出现在材料作者字段。

**不能核对**：文献是否真实存在于现实世界（材料没给 DOI/数据库时）、标题是否逐字正确（材料本身可能就写错）、转述是否与原文语义一致。

产物必须把"核对了什么、没核对什么"写进 `uncertainty`。特别是：材料只有正文、没有参考文献表时，明确写"无法验证文献真实存在"。

## 循环溯源防护

成稿与自身输出不得作为材料来源：

- `skip_set()` 按**精确相对路径**排除 `--draft` 指定的成稿和 `--out` 输出目录；
- 不按文件名全局排除——材料里真有一篇叫 `methods.md` 时不该被丢掉；
- 防止成稿里的错值给自己做出处（05 题踩过的坑，08 同样适用）。
