# 失败模式与诊断词表说明

## 1. 有量化数据的硬失败：引用幻觉

| 来源 | 数据 | 对本 Skill 的含义 |
|---|---|---|
| 引用幻觉综述（引 Agrawal et al. 2024） | CS 引用标题幻觉率 47%（GPT-4）～77%（Llama 2 7B）；编造引用的作者列表不一致，真实引用作者 recall 准确 | 只查作者不够，年份/标题都要查 |
| Sage 2026 混合方法研究（DOI 10.1177/20552076261493048） | 研究方案中 ChatGPT 引用 28/178 = 15.7% 完全编造；引用任务幻觉率 96.9% | 必须有"引用查不到原文"的显式状态，不能默认通过 |
| 同一 Sage 研究 | "Frankenstein 混合幻觉"（真作者 + 假 DOI/假年份）通过浅层检查 | 本 Skill 专门实现"真作者 + 错年份"的逐字段核对 |
| Min et al. 2023 FActScore | 事实精度从常见实体 80% 降到稀有实体 16% | 冷门方向不能放宽核对 |

这些数据的用途是说明**为什么元数据核对必须逐字段、必须有状态**，不是拿来当本 Skill 的成绩。

## 2. 写作通病（公开写作指导，非学术实证，仅列失败模式）

| 通病 | 表现 | 对应检查项 |
|---|---|---|
| 背景空转 | "随着…快速发展""近年来受到广泛关注""具有重要意义" | `cliche_background` |
| 文献流水账 | "A 做了…；B 做了…；C 提出…" | `related_work_no_grouping` |
| 缺口模糊 | "现有研究仍存在不足""研究不够充分" | `gap_without_citation` |
| 夸大创新 | "首次""开创性""填补国内外空白""彻底解决" | `hedge_overclaim` |
| 引言结论重复 | 引言写出具体实验数据，与结论章混同 | `contribution_without_figure`（贡献无正确定位） |

## 3. 词表的使用原则（重要）

`assets/lexicon.json` 里的 `cliche_terms`、`overclaim_terms`、`hedge_terms`、`gap_signals`、`contribution_signals` 全部是**诊断信号**，不是禁令：

- 命中只产生 warn 与 gaps.md 里的追问，**不自动删除或改写**；
- 自动删会伤语义——比如"近年来"在真实时间脉络里是合理的；
- 判断权在作者：Skill 给"哪里可疑 + 为什么可疑"，作者决定改不改。

## 4. 开发中真实遇到并修掉的失败（不是假想的）

| # | 现象 | 根因 | 修法 |
|---|---|---|---|
| 1 | 好稿 trace_rate 只有 0.067，13 句 unanchored | 标题行被当断言；`et al.`/`Fig.` 后的句点把一句切两句 | 排除标题行、保护缩写后再切句 |
| 2 | 运行崩溃 `NoneType.strip()` | 中文括号引用有可选捕获组，值为 None | 遍历所有组取第一个非空，回退整句 |
| 3 | 所有引用判 unverified | 同一条引用被两个模式重复匹配，裸 `(2020)` 解析不到 | 重叠区间去重；author-year 用整个匹配解析 |
| 4 | 错年份 2019 报 unverified 而非精确错配 | 作者对了但年份不在材料 → 直接返回 None | 作者匹配到真实文献即绑定，再逐字段报 `year 2019 != material 2020` |
| 5 | 无 draft 却返回 complete | 门禁没有断言行可判；status 判定漏了"无稿"条件 | 无 draft 强制 partial + limits |
| 6 | 真实 arXiv 论文 0 条参考文献 | 用 `\bibitem{}` 内嵌参考文献，不是 `.bib` | 新增 `\bibitem` 解析，0 → 40 条 |
| 7 | LaTeX `%` 注释被当断言 | 注释行没排除 | 整行注释与行尾注释都剥离 |

每一条都对应 `assets/tests/run_selftest.py` 里的一个断言，防止回归。
