# 文献库字段字典

文献库是 JSON，支持三种顶层形态：`[...]`、`{"key": {...}}`、`{"entries": [...]}`。每个条目至少要有可唯一识别的 `key`。

| 字段 | 类型 | 作用 | 缺失后果 |
|---|---|---|---|
| `key` | 字符串 | 条目唯一标识，键式引用 `\cite{key}` 直接匹配 | 自动生成 `entryN`，但可读性差、易冲突 |
| `order` | 整数 | 顺序编码制 `[n]` 的编号 | 按列表位置推断；与正文对不上时会报 mismatch |
| `authors` / `author` | 字符串或数组 | 第一作者用于去重判据；缺则 `missing_required_field` | 硬错误 |
| `title` | 字符串 | 去重主判据（NFKC + 去标点） | 硬错误 |
| `year` | 数字或字符串 | 去重辅助；全角数字可接受 | 硬错误 |
| `venue` | 字符串 | 期刊/出版社，格式转换时保留 | 不阻断，格式转换时列 unavailable |
| `volume` / `issue` / `pages` | 字符串 | GB/T 7714 卷期页；合并时从更完整的条目继承 | 警告，不臆造 |
| `doi` | 字符串 | **强去重证据**；`10.x/...` 或 `https://doi.org/10.x/...` 均可 | 用题名+作者+年份弱判据，仅提示不合并 |
| `type` / `type_label` | 字符串 | `[J]`、`[M]`、`[EB/OL]`、`article-journal`、`preprint` 等 | 预印本类型无法自动判断 |
| `is_preprint` | 布尔 | **预印本兜底标记**，不依赖 URL/题名关键词 | 新型预印本平台可能漏检 |
| `url` | 字符串 | 电子资源链接；含 `arxiv.org` 是预印本线索 | 不阻断 |
| `access_date` / `accessed` | 字符串 | `[引用日期]`，电子资源必需 | 警告 `missing_access_date` |

## 规范化规则（脚本内部，写文档是为了让人能复核）

1. 所有字符串先做 **NFKC**：全角 `２０２６` → `2026`，全角标点 → 半角。
2. 连字折叠：`ﬀ`、`ﬁ`、`ﬂ` → `ff`/`fi`/`fl`；`–`/`—` → `-`。
3. DOI 去前缀：去 `https://doi.org/`、`doi:`，去尾部标点，转小写。
4. 题名键：只保留字母、数字、汉字，用于相似度比对。
5. 第一作者姓：西文取逗号前或最后一个词；中文取 2–4 字连续汉字。

## 字段保留原则

- 合并两条同 DOI 条目时，逐字段取"更完整"的那条（有卷期页的优先），并在 `duplicate_decisions[].merged_fields` 留下合并后全字段。
- 缺字段写 `unavailable`，不要填空字符串冒充有值，更不要根据记忆补。
